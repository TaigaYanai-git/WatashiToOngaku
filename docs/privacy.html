Our Music プライバシーポリシー

制定日：2026年10月21日

「Our Music」（以下「本アプリ」）における利用者情報の取り扱いについて説明します。

1. 取得する情報

本アプリは、利用者が選んだ曲の情報（曲名・アーティスト名・アルバム名・ジャケット画像のURL・試聴用URL・Apple Musicのリンク）、日付、ひとことメモ、表示や通知の設定を扱います。

2. 保存場所と外部送信

上記の情報はすべて利用者の端末内にのみ保存されます。開発者を含む第三者のサーバーへ送信することはありません。本アプリは広告・アクセス解析・トラッキングの仕組みを使用していません。

3. Apple Music の利用

曲の検索・試聴・ジャケット画像の表示のため、利用者の許可を得て Apple の MusicKit を利用します。検索した語句は曲を探すために Apple に送信され、Apple のプライバシーポリシーに従って取り扱われます。

4. 通知

毎日のリマインダーは端末内で予約されるローカル通知です。外部サーバーは使用しません。

5. 情報の削除

アプリ内で曲の記録を外すか、本アプリを端末から削除すると、保存された情報は削除されます。

6. お問い合わせ

GitHub Issues からご連絡ください。

7. 改定

本ポリシーを改定する場合は、このページで告知します。
